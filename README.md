# AI Content Platform Backend

Backend API for AI-powered article generation built with Django REST Framework and Google Gemini.

## Overview

AI Content Platform is a content generation service that allows users to create articles with different tones and lengths using generative AI models.

The platform exposes REST APIs that can be integrated with web and mobile applications.

## Features

- AI article generation
- Google Gemini integration
- Custom tone selection
- Custom article length
- REST API architecture
- User authentication support

## Tech Stack

### Backend

- Python
- Django
- Django REST Framework
- Google Gemini API
